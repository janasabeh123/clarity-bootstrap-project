# Clarity — Bootstrap 5 Digital Agency Website

A one-page responsive agency site built for the Bootstrap project brief.

## Files
- `index.html` — page markup and Bootstrap components
- `css/style.css` — custom theme, layout, responsive styling
- `js/main.js` — portfolio filters and client-side form validation demo
- `images/` — reserved folder for local image assets (the current demo uses Unsplash image URLs)

## Run
Open `index.html` in a browser. Internet access is required for Bootstrap, Bootstrap Icons, Google Fonts, and the demo images.

## Theme
Midnight Navy `#0B1020`, Card Navy `#171F35`, Electric Violet `#8B5CF6`, Mint `#56D6C9`, Soft White `#F4F6FC`.

## Included Bootstrap features
Responsive navbar/collapse, dropdown, grid with responsive breakpoints, buttons, cards, form controls, Bootstrap Icons, accordion, spacing/display/flex utilities, responsive images.

## Note
The contact form is front-end validation only; it does not send messages until connected to a backend or email provider.
